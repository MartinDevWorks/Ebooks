# Somos Todo

Sitio web oficial del proyecto **Somos Todo**, enfocado en superación personal,
conciencia, abundancia y crecimiento interior.

Este repositorio contiene únicamente el código del sitio web
(HTML, CSS y JavaScript).

## Contenido del proyecto
- Página principal
- Blog de artículos reflexivos
- Páginas de ebooks (landing pages)
- Página de contacto
- Páginas de agradecimiento post-compra

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- GitHub Pages (para despliegue)

## Importante
Los ebooks en PDF **no están incluidos en este repositorio**.
El contenido comercial se distribuye exclusivamente a través del sitio oficial.
